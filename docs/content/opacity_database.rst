Opacity Database
==========================

POSEIDON's opacity database includes high-resolution (:math:`R \sim 10^6`) 
line-by-line absorption cross sections, continuum absorption, aerosol Mie scattering 
properties, and surface albedos. 

The sections below describe each of the opacity databases included in POSEIDON.
